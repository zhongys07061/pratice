# quiz_app

声明：该项目全程由AI生成，主要使用的是deepseek-V4-pro模型。

概述：该项目是安卓手机的app，能够导入选择题和判断题用来练习，起初是因为我大一下学期挂科了，导致要补考，所以想用AI做一个能在手机上就能刷题的app，主要是选择和判断题
，因为老师给的题库就是几百道选择和判断题，所以该app的功能只是用来导入题目并刷题。
